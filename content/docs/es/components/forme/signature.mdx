## Referencia de la API

### PdfSignatureBlock

| Prop      | Tipo                                 | Predeterminado |
| --------- | ------------------------------------ | -------------- |
| `variant` | `'single' \| 'double' \| 'inline'`   | 'single'       |
| `label`   | `string`                             | -              |
| `name`    | `string`                             | -              |
| `title`   | `string`                             | -              |
| `date`    | `string`                             | -              |
| `signers` | `[SignatureSigner, SignatureSigner]` | -              |
| `style`   | `Style`                              | -              |
