## Referencia de la API

### PdfQRCode

| Prop              | Tipo                       | Predeterminado |
| ----------------- | -------------------------- | -------------- |
| `value`           | `string`                   | -              |
| `size`            | `number`                   | -              |
| `color`           | `string`                   | -              |
| `backgroundColor` | `string`                   | -              |
| `errorLevel`      | `'L' \| 'M' \| 'Q' \| 'H'` | -              |
| `margin`          | `number`                   | -              |
| `caption`         | `string`                   | -              |
| `children`        | `never`                    | -              |
