| `marginBottom` | `number`                                                                                          | -              |
| `address`      | `string`                                                                                          | -              |
| `phone`        | `string`                                                                                          | -              |
| `email`        | `string`                                                                                          | -              |
| `logo`         | `ReactNode`                                                                                       | -              |
| `fixed`        | `boolean`                                                                                         | `false`        |
| `noWrap`       | `boolean`                                                                                         | `true`         |
