## Referencia de la API

### PdfPageNumber

| Propiedad  | Tipo                            | Predeterminado             |
| ---------- | ------------------------------- | -------------------------- |
| `format`   | `string`                        | `'Page {page} of {total}'` |
| `align`    | `'left' \| 'center' \| 'right'` | `'center'`                 |
| `size`     | `'xs' \| 'sm' \| 'md'`          | `'sm'`                     |
| `fixed`    | `boolean`                       | `false`                    |
| `muted`    | `boolean`                       | `true`                     |
| `children` | `never`                         | -                          |
