## Referencia de la API

### PdfCard

| Propiedad  | Tipo                                 | Valor predeterminado |
| ---------- | ------------------------------------ | -------------------- |
| `title`    | `string`                             | -                    |
| `children` | `ReactNode`                          | -                    |
| `variant`  | `'default' \| 'bordered' \| 'muted'` | `'default'`          |
| `padding`  | `'sm' \| 'md' \| 'lg'`               | `'md'`               |
| `wrap`     | `boolean`                            | `false`              |
