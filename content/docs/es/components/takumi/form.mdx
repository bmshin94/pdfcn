## Uso

```tsx
import { PdfForm } from "@/components/pdf/form";
```

```tsx
<PdfForm title="Contact" groups={[{ fields: [{ label: "Email" }] }]} />
```

### Variantes

```tsx
<PdfForm
  variant="outlined"
  labelPosition="left"
  groups={[{ title: "Contact", layout: "two-column", fields }]}
/>
```

## Referencia de la API

### PdfForm

| Propiedad       | Tipo                                            | Valor predeterminado |
| --------------- | ----------------------------------------------- | -------------------- |
| `title`         | `string`                                        | -                    |
| `subtitle`      | `string`                                        | -                    |
| `groups`        | `PdfFormGroup[]`                                | -                    |
| `variant`       | `'underline' \| 'box' \| 'outlined' \| 'ghost'` | `'underline'`        |
| `labelPosition` | `'above' \| 'left'`                             | `'above'`            |
| `noWrap`        | `boolean`                                       | `false`              |
| `style`         | `Style`                                         | -                    |

Los grupos admiten los diseños `single`, `two-column` y `three-column`.
