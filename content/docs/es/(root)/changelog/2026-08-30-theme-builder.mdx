Lanzamos el Constructor de temas — un editor visual para personalizar temas de PDF con vista previa en vivo, retroalimentación instantánea y exportación de código con un clic.

### Novedades

- **Vista previa de PDF en vivo** — Ve tu tema aplicado en tiempo real mientras ajustas colores, tipografía, espaciado y configuración de página
- **Selector de temas** — Explora y cambia entre 9 [preajustes](/docs/themes) integrados (Professional, Modern, Minimal, Executive, Corporate, Elegant, Vivid, Forest, Blueprint)
- **Deshacer / Rehacer** — Historial completo con atajos de teclado (⌘Z / ⌘⇧Z)
- **Exportación de código** — Copia la configuración del tema como objeto JSON o preajuste de TypeScript para incorporarlo en tu proyecto
- **URLs compartibles** — El estado del tema se codifica en el hash de la URL, para que puedas compartir una configuración exacta con cualquiera
- **Enrutamiento específico por base** — Constructores de temas independientes para [Takumi PDF](/theme-builder/takumi) y [Forme PDF](/theme-builder/forme)
- **Vista previa de fuentes** — Observa cómo se ven tus fuentes de cuerpo y encabezado elegidas a tamaño real antes de generar un PDF
