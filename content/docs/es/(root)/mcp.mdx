[MCP](https://modelcontextprotocol.io/) es un protocolo abierto que estandariza cómo las aplicaciones proporcionan contexto a los LLM. El CLI de shadcn puede registrar un servidor MCP para que su editor pueda descubrir componentes del registro—incluyendo los elementos que instala desde **pdfcn** a través del mismo CLI.

## Configurar MCP

Ejecute:

```bash
npx shadcn@latest mcp init
```

Elija su cliente MCP cuando se le solicite, luego habilite el servidor MCP en ese cliente para completar la configuración.

## Uso

Con MCP habilitado, puede pedir a su IDE que trabaje con patrones **Takumi** y **Forme** y componentes del registro pdfcn. Ejemplos de prompts:

- Construir un layout de factura con **Table**, **Heading**, **Text** y **KeyValue**.
- Agregar un **QRCode** y **Signature** a un documento PDF.
- Crear un informe con **Graph**, **DataTable** y **PageHeader**.
- Disponer un PDF usando **Section**, **Stack**, **Divider** y **KeepTogether**.
- Implementar un flujo de múltiples páginas con **PageBreak**, **PageNumber** y **PageFooter**.

Instale componentes desde este registro con `npx shadcn@latest add` y la URL JSON de cada página de documentación. Los componentes funcionan con valores predeterminados razonables.
