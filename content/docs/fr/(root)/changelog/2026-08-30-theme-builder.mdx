Nous avons lancé le Générateur de thèmes — un éditeur visuel pour personnaliser les thèmes PDF avec aperçu en direct, retour instantané et export de code en un clic.

### Nouveautés

- **Aperçu PDF en direct** — Visualisez votre thème appliqué en temps réel pendant que vous ajustez les couleurs, la typographie, les espacements et les paramètres de page
- **Sélecteur de thème** — Parcourez et basculez entre 9 [préréglages](/docs/themes) intégrés (Professional, Modern, Minimal, Executive, Corporate, Elegant, Vivid, Forest, Blueprint)
- **Annuler / Rétablir** — Historique complet avec raccourcis clavier (⌘Z / ⌘⇧Z)
- **Export de code** — Copiez la configuration du thème sous forme d'objet JSON ou de préréglage TypeScript à intégrer dans votre projet
- **URL partageables** — L'état du thème est encodé dans le hash de l'URL afin que vous puissiez partager une configuration exacte avec n'importe qui
- **Routage spécifique par base** — Générateurs de thèmes distincts pour [Takumi PDF](/theme-builder/takumi) et [Forme PDF](/theme-builder/forme)
- **Aperçu des polices** — Visualisez à taille réelle vos polices de corps et de titre choisies avant de générer un PDF
