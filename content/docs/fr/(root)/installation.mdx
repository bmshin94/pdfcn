## Prérequis

Un projet React pouvant exécuter [Takumi](https://takumi.kane.tw/docs/pdf) ou [Forme](https://docs.formepdf.com).

## Installation

Exécutez la commande suivante pour ajouter un composant Takumi :

```bash
npx shadcn@latest add @pdfcn/takumi/text
```

Les composants Forme utilisent l'espace de noms `forme/` :

```bash
npx shadcn@latest add @pdfcn/forme/text
```

Le registre installe les dépendances du renderer correspondantes et les utilitaires de thème partagés requis par le composant sélectionné.

## Utilisation

Importez le composant installé et utilisez-le dans les primitives de document de votre renderer :

```tsx
import { Document, Page } from "@/components/pdf/pdf-primitives";
import { PdfcnThemeProvider } from "@/components/pdf/theme-provider";
import { Text } from "@/components/pdf/text";

export function Invoice() {
  return (
    <Document>
      <Page size="A4">
        <PdfcnThemeProvider>
          <Text variant="xl">Invoice</Text>
        </PdfcnThemeProvider>
      </Page>
    </Document>
  );
}
```

Pour Forme, utilisez `Document` et `Page` depuis `@formepdf/react` ; l'API du composant pdfcn installé reste la même.

## Installer un bloc

Les blocs sont des modèles de documents complets composés à partir de composants du registre :

```bash
npx shadcn@latest add @pdfcn/takumi/invoice-minimal
```

Utilisez l'espace de noms `forme/` pour le document Forme équivalent :

```bash
npx shadcn@latest add @pdfcn/forme/invoice-minimal
```

## Installer un thème

pdfcn fournit des presets de thèmes qui s'intègrent avec `PdfcnThemeProvider` :

```bash
npx shadcn@latest add @pdfcn/takumi/theme-minimal
```

Pour Forme :

```bash
npx shadcn@latest add @pdfcn/theme-minimal
```
