[MCP](https://modelcontextprotocol.io/) est un protocole ouvert qui standardise la manière dont les applications fournissent du contexte aux LLM. Le CLI de shadcn peut enregistrer un serveur MCP afin que votre éditeur puisse découvrir les composants du registre—incluant les éléments que vous installez depuis **pdfcn** via le même CLI.

## Configurer MCP

Exécutez :

```bash
npx shadcn@latest mcp init
```

Choisissez votre client MCP lorsque demandé, puis activez le serveur MCP dans ce client pour finaliser la configuration.

## Utilisation

Avec MCP activé, vous pouvez demander à votre IDE de travailler avec les motifs **Takumi** et **Forme** et les composants du registre pdfcn. Exemples de prompts :

- Construire une disposition de facture avec **Table**, **Heading**, **Text** et **KeyValue**.
- Ajouter un **QRCode** et une **Signature** à un document PDF.
- Créer un rapport avec **Graph**, **DataTable** et **PageHeader**.
- Disposer un PDF en utilisant **Section**, **Stack**, **Divider** et **KeepTogether**.
- Implémenter un flux multi-pages avec **PageBreak**, **PageNumber** et **PageFooter**.

Installez des composants depuis ce registre avec `npx shadcn@latest add` et l'URL JSON de chaque page de documentation. Les composants fonctionnent avec des valeurs par défaut raisonnables.
