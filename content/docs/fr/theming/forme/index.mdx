## Utilisation

```tsx
import { PdfcnThemeProvider } from "@/components/pdf/theme-provider";
import { professionalTheme } from "@/lib/pdf-themes/professional";

export function Invoice() {
  return (
    <PdfcnThemeProvider theme={professionalTheme}>
      {/* Your PDF content */}
    </PdfcnThemeProvider>
  );
}
```

## Jetons de couleur

Toutes les valeurs de couleur doivent être des chaînes hexadécimales (par exemple, `#1a1a1a`). React PDF prend en charge hex, `rgb()` et `hsl()`, mais PAS `oklch`.

| Jeton               | Objectif                              |
| ------------------- | ------------------------------------- |
| `foreground`        | Couleur de texte principale           |
| `background`        | Arrière-plan de la page               |
| `muted`             | Arrière-plans secondaires             |
| `mutedForeground`   | Légendes, notes de bas de page        |
| `primary`           | Couleur de marque/accent              |
| `primaryForeground` | Texte sur les arrière-plans primaires |
| `border`            | Bordures de tableau, séparateurs      |
| `accent`            | Éléments d'appel à l'action           |
| `destructive`       | États d'erreur                        |
| `success`           | États de réussite                     |
| `warning`           | États d'avertissement                 |
| `info`              | États d'information                   |

## Jetons primitifs

Les primitives définissent les échelles de conception brutes disponibles pour les thèmes :

- **Échelle typographique** — ratio de tierce majeure (1,25) avec une base de 12pt
- **Échelle d'espacement** — système de grille de 4pt
- **Graisses de police** — 400–700
- **Hauteurs de ligne** — 1,2–1,6
- **Rayon de bordure** — 0–8pt

## Thèmes personnalisés

Utilisez l'interface `PdfcnTheme` pour créer des thèmes personnalisés tout en conservant la forme complète du thème.

```tsx
import type { PdfcnTheme } from "@/registry/themes";
import { defaultPrimitives } from "@/registry/themes";

export const oceanTheme: PdfcnTheme = {
  name: "ocean",
  primitives: defaultPrimitives,
  colors: {
    foreground: "#0f172a",
    background: "#ffffff",
    primary: "#0369a1",
    accent: "#0ea5e9",
    muted: "#f1f5f9",
    border: "#e2e8f0",
    mutedForeground: "#64748b",
    primaryForeground: "#ffffff",
    destructive: "#dc2626",
    success: "#16a34a",
    warning: "#d97706",
    info: "#0ea5e9",
  },
  typography: {
    body: { fontFamily: "Helvetica", fontSize: 11, lineHeight: 1.6 },
    heading: {
      fontFamily: "Times-Roman",
      fontWeight: 700,
      lineHeight: 1.25,
      fontSize: { h1: 32, h2: 24, h3: 20, h4: 16, h5: 14, h6: 12 },
    },
  },
  spacing: {
    page: { marginTop: 56, marginRight: 48, marginBottom: 56, marginLeft: 48 },
    sectionGap: 28,
    paragraphGap: 10,
    componentGap: 14,
  },
  page: { size: "A4", orientation: "portrait" },
};
```
