## Référence de l'API

### PdfPageNumber

| Propriété  | Type                            | Par défaut                                   |
| ---------- | ------------------------------- | -------------------------------------------- |
| `format`   | `string`                        | 'Page &#123;page&#125; of &#123;total&#125;' |
| `align`    | `'left' \| 'center' \| 'right'` | 'center'                                     |
| `size`     | `'xs' \| 'sm' \| 'md'`          | 'sm'                                         |
| `fixed`    | `boolean`                       | false                                        |
| `muted`    | `boolean`                       | true                                         |
| `children` | `never`                         | -                                            |
