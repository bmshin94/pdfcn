## Référence de l'API

### Section

| Prop          | Type                                              | Par défaut |
| ------------- | ------------------------------------------------- | ---------- |
| `spacing`     | `'none' \| 'sm' \| 'md' \| 'lg' \| 'xl'`          | 'md'       |
| `padding`     | `'none' \| 'sm' \| 'md' \| 'lg'`                  | -          |
| `background`  | `string`                                          | -          |
| `border`      | `boolean`                                         | false      |
| `variant`     | `'default' \| 'callout' \| 'highlight' \| 'card'` | 'default'  |
| `accentColor` | `string`                                          | -          |
| `noWrap`      | `boolean`                                         | false      |
