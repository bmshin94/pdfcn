## Utilisation

```tsx
import { PdfForm } from "@/components/pdf/form";
```

```tsx
<PdfForm title="Contact" groups={[{ fields: [{ label: "Email" }] }]} />
```

### Variantes

```tsx
<PdfForm
  variant="outlined"
  labelPosition="left"
  groups={[{ title: "Contact", layout: "two-column", fields }]}
/>
```

## Référence de l'API

### PdfForm

| Propriété       | Type                                            | Valeur par défaut |
| --------------- | ----------------------------------------------- | ----------------- |
| `title`         | `string`                                        | -                 |
| `subtitle`      | `string`                                        | -                 |
| `groups`        | `PdfFormGroup[]`                                | -                 |
| `variant`       | `'underline' \| 'box' \| 'outlined' \| 'ghost'` | `'underline'`     |
| `labelPosition` | `'above' \| 'left'`                             | `'above'`         |
| `noWrap`        | `boolean`                                       | `false`           |
| `style`         | `Style`                                         | -                 |

Les groupes prennent en charge les mises en page `single`, `two-column` et `three-column`.
