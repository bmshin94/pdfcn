## Utilisation

```tsx
import { PdfQRCode } from "@/components/pdf/qrcode";
```

```tsx
<PdfQRCode value="https://pdfcn.dev" />
```

## Référence de l'API

### PdfQRCode

| Propriété         | Type                       | Par défaut |
| ----------------- | -------------------------- | ---------- |
| `value`           | `string`                   | -          |
| `size`            | `number`                   | -          |
| `color`           | `string`                   | -          |
| `backgroundColor` | `string`                   | -          |
| `errorLevel`      | `'L' \| 'M' \| 'Q' \| 'H'` | -          |
| `margin`          | `number`                   | -          |
| `caption`         | `string`                   | -          |
| `children`        | `never`                    | -          |
