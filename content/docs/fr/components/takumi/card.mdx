
## Référence de l'API

### PdfCard

| Propriété  | Type                                 | Valeur par défaut |
| ---------- | ------------------------------------ | ----------------- |
| `title`    | `string`                             | -                 |
| `children` | `ReactNode`                          | -                 |
| `variant`  | `'default' \| 'bordered' \| 'muted'` | `'default'`       |
| `padding`  | `'sm' \| 'md' \| 'lg'`               | `'md'`            |
| `wrap`     | `boolean`                            | `false`           |
