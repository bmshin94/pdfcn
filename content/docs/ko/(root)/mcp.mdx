[MCP](https://modelcontextprotocol.io/)는 애플리케이션이 LLM에 컨텍스트를 제공하는 방법을 표준화하는 오픈 프로토콜입니다. shadcn CLI는 MCP 서버를 등록하여 편집기가 레지스트리 컴포넌트를 발견할 수 있도록 합니다——동일한 CLI를 통해 **pdfcn**에서 설치한 항목도 포함됩니다.

## MCP 구성

다음을 실행합니다:

```bash
npx shadcn@latest mcp init
```

프롬프트에서 MCP 클라이언트를 선택한 후 해당 클라이언트에서 MCP 서버를 활성화하여 설정을 완료합니다.

## 사용법

MCP가 활성화되면 IDE에 **Takumi** 및 **Forme** 패턴과 pdfcn 레지스트리 컴포넌트를 사용하도록 요청할 수 있습니다. 예시 프롬프트:

- **Table**, **Heading**, **Text**, **KeyValue**를 사용하여 송장 레이아웃을 구축합니다.
- PDF 문서에 **QRCode**와 **Signature**를 추가합니다.
- **Graph**, **DataTable**, **PageHeader**를 사용하여 보고서를 만듭니다.
- **Section**, **Stack**, **Divider**, **KeepTogether**를 사용하여 PDF를 레이아웃합니다.
- **PageBreak**, **PageNumber**, **PageFooter**를 사용하여 다중 페이지 흐름을 구현합니다.

`npx shadcn@latest add`와 각 문서 페이지의 JSON URL을 사용하여 이 레지스트리에서 컴포넌트를 설치합니다. 컴포넌트는 적절한 기본값으로 작동합니다.
