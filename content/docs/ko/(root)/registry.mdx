**pdfcn** 레지스트리는 [shadcn 레지스트리 형식](https://ui.shadcn.com/docs/registry)으로 Takumi 및 Forme 컴포넌트, 블록 및 테마를 제공합니다. `components.json`에 네임스페이스를 한 번 등록한 후 CLI를 사용하여 이름으로 항목을 가져옵니다.

## 설정

이 사이트의 **registries** 항목을 추가합니다. 모든 `components.json` 필드와 동작에 대해서는 [shadcn 레지스트리 문서](https://ui.shadcn.com/docs/registry)를 참조하세요.

```json
{
  "registries": {
    "@pdfcn": "https://pdfcn.dev/r/{name}.json"
  }
}
```

`@pdfcn`을 다른 네임스페이스로 교체할 수 있습니다. `shadcn add`에 전달하는 것과 일치하면 됩니다.

## 사용법

항목은 기본별로 네임스페이스가 지정됩니다: Takumi는 `takumi/`, Forme는 `forme/`입니다.

레지스트리 파일은 다음 대상 경로를 따릅니다:

- 컴포넌트는 `components/ui/`에 설치됩니다.
- 블록은 구성된 블록 디렉토리에 설치됩니다.

컴포넌트는 의존성을 선언하므로 컴포넌트를 설치할 때 추가 설정이 필요하지 않습니다.

### Takumi

컴포넌트 설치:

```bash
npx shadcn@latest add @pdfcn/takumi/text
```

블록 설치:

```bash
npx shadcn@latest add @pdfcn/takumi/invoice-minimal
```

레지스트리 별칭을 사용하지 않을 때 전체 URL을 사용합니다(각 문서 페이지에 표시됨):

```bash
npx shadcn@latest add https://pdfcn.dev/r/takumi/text.json
```

### Forme

컴포넌트 설치:

```bash
npx shadcn@latest add @pdfcn/forme/text
```

블록 설치:

```bash
npx shadcn@latest add @pdfcn/forme/invoice-minimal
```

레지스트리 별칭을 사용하지 않을 때 전체 URL을 사용합니다(각 문서 페이지에 표시됨):

```bash
npx shadcn@latest add https://pdfcn.dev/r/forme/text.json
```
