## 전제 조건

[Takumi](https://takumi.kane.tw/docs/pdf) 또는 [Forme](https://docs.formepdf.com)를 실행할 수 있는 React 프로젝트.

## 설치

다음 명령을 실행하여 Takumi 컴포넌트를 추가합니다:

```bash
npx shadcn@latest add @pdfcn/takumi/text
```

Forme 컴포넌트는 `forme/` 네임스페이스를 사용합니다:

```bash
npx shadcn@latest add @pdfcn/forme/text
```

레지스트리는 일치하는 런타임 의존성과 선택된 컴포넌트에 필요한 공유 테마 유틸리티를 설치합니다.

## 사용법

설치된 컴포넌트를 가져와 런타임의 문서 프리미티브 내에서 사용합니다:

```tsx
import { Document, Page } from "@/components/pdf/pdf-primitives";
import { PdfcnThemeProvider } from "@/components/pdf/theme-provider";
import { Text } from "@/components/pdf/text";

export function Invoice() {
  return (
    <Document>
      <Page size="A4">
        <PdfcnThemeProvider>
          <Text variant="xl">Invoice</Text>
        </PdfcnThemeProvider>
      </Page>
    </Document>
  );
}
```

Forme의 경우 `@formepdf/react`에서 `Document`와 `Page`를 사용합니다. 설치된 pdfcn 컴포넌트 API는 동일합니다.

## 블록 설치

블록은 레지스트리 컴포넌트로 구성된 완전한 문서 템플릿입니다:

```bash
npx shadcn@latest add @pdfcn/takumi/invoice-minimal
```

`forme/` 네임스페이스를 사용하여 동등한 Forme 문서를 가져옵니다:

```bash
npx shadcn@latest add @pdfcn/forme/invoice-minimal
```

## 테마 설치

pdfcn은 `PdfcnThemeProvider`와 통합되는 테마 프리셋을 제공합니다:

```bash
npx shadcn@latest add @pdfcn/takumi/theme-minimal
```

Forme의 경우:

```bash
npx shadcn@latest add @pdfcn/theme-minimal
```
