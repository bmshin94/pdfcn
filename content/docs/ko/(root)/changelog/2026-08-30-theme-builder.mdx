테마 빌더를 출시했습니다 — 실시간 미리보기, 즉각적인 피드백, 원클릭 코드 내보내기를 제공하는 PDF 테마 커스터마이징용 시각적 편집기입니다.

### 새로운 기능

- **실시간 PDF 미리보기** — 색상, 타이포그래피, 여백, 페이지 설정을 조정하는 즉시 테마 적용 결과를 실시간으로 확인
- **테마 선택기** — 9가지 기본 제공 [프리셋](/docs/themes)(Professional, Modern, Minimal, Executive, Corporate, Elegant, Vivid, Forest, Blueprint)을 둘러보고 전환
- **실행 취소 / 다시 실행** — 키보드 단축키(⌘Z / ⌘⇧Z)를 지원하는 전체 히스토리
- **코드 내보내기** — 테마 설정을 JSON 객체 또는 TypeScript 프리셋으로 복사하여 프로젝트에 바로 적용
- **공유 가능한 URL** — 테마 상태가 URL 해시에 인코딩되어 있어 정확한 구성을 누구와도 공유 가능
- **베이스별 라우팅** — [Takumi PDF](/theme-builder/takumi)와 [Forme PDF](/theme-builder/forme)를 위한 별도의 테마 빌더 제공
- **폰트 미리보기** — PDF를 생성하기 전에 선택한 본문 및 제목 글꼴을 실제 크기로 확인
