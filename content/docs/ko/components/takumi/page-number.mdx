## API 참조

### PdfPageNumber

| 속성       | 타입                            | 기본값                     |
| ---------- | ------------------------------- | -------------------------- |
| `format`   | `string`                        | `'Page {page} of {total}'` |
| `align`    | `'left' \| 'center' \| 'right'` | `'center'`                 |
| `size`     | `'xs' \| 'sm' \| 'md'`          | `'sm'`                     |
| `fixed`    | `boolean`                       | `false`                    |
| `muted`    | `boolean`                       | `true`                     |
| `children` | `never`                         | -                          |
