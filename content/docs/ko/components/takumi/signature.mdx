### PdfSignatureBlock

| 속성      | 타입                                 | 기본값     |
| --------- | ------------------------------------ | ---------- |
| `variant` | `'single' \| 'double' \| 'inline'`   | `'single'` |
| `label`   | `string`                             | -          |
| `name`    | `string`                             | -          |
| `title`   | `string`                             | -          |
| `date`    | `string`                             | -          |
| `signers` | `[SignatureSigner, SignatureSigner]` | -          |
| `style`   | `Style`                              | -          |
