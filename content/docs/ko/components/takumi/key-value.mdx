
```tsx

```

## API 참조

### KeyValue

| 속성               | 타입                         | 기본값         |
| ------------------ | ---------------------------- | -------------- |
| `items`            | `KeyValueEntry[]`            | -              |
| `direction`        | `'horizontal' \| 'vertical'` | `'horizontal'` |
| `divided`          | `boolean`                    | `false`        |
| `size`             | `'sm' \| 'md' \| 'lg'`       | `'md'`         |
| `labelFlex`        | `number`                     | `1`            |
| `labelColor`       | `string`                     | -              |
| `valueColor`       | `string`                     | -              |
| `boldValue`        | `boolean`                    | `false`        |
| `noWrap`           | `boolean`                    | `false`        |
| `dividerColor`     | `string`                     | -              |
| `dividerThickness` | `number`                     | -              |
| `dividerMargin`    | `number`                     | -              |
