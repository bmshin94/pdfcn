## API 참조

### PdfPageNumber

| 속성       | 타입                            | 기본값                                       |
| ---------- | ------------------------------- | -------------------------------------------- |
| `format`   | `string`                        | 'Page &#123;page&#125; of &#123;total&#125;' |
| `align`    | `'left' \| 'center' \| 'right'` | 'center'                                     |
| `size`     | `'xs' \| 'sm' \| 'md'`          | 'sm'                                         |
| `fixed`    | `boolean`                       | false                                        |
| `muted`    | `boolean`                       | true                                         |
| `children` | `never`                         | -                                            |
