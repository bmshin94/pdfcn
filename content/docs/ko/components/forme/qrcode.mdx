## API 참조

### PdfQRCode

| 속성              | 타입                       | 기본값 |
| ----------------- | -------------------------- | ------ |
| `value`           | `string`                   | -      |
| `size`            | `number`                   | -      |
| `color`           | `string`                   | -      |
| `backgroundColor` | `string`                   | -      |
| `errorLevel`      | `'L' \| 'M' \| 'Q' \| 'H'` | -      |
| `margin`          | `number`                   | -      |
| `caption`         | `string`                   | -      |
| `children`        | `never`                    | -      |
