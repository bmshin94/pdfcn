## API 레퍼런스

### PdfCard

| 속성       | 타입                                 | 기본값      |
| ---------- | ------------------------------------ | ----------- |
| `title`    | `string`                             | -           |
| `children` | `ReactNode`                          | -           |
| `variant`  | `'default' \| 'bordered' \| 'muted'` | `'default'` |
| `padding`  | `'sm' \| 'md' \| 'lg'`               | `'md'`      |
| `wrap`     | `boolean`                            | `false`     |
