我们发布了主题构建器——一款用于自定义 PDF 主题的可视化编辑器，支持实时预览、即时反馈和一键代码导出。

### 新增功能

- **实时 PDF 预览** — 在调整颜色、字体、间距和页面设置时，实时查看主题应用效果
- **主题选择器** — 浏览并切换 9 种内置[预设](/docs/themes)（Professional、Modern、Minimal、Executive、Corporate、Elegant、Vivid、Forest、Blueprint）
- **撤销 / 重做** — 完整的历史记录，支持键盘快捷键（⌘Z / ⌘⇧Z）
- **代码导出** — 将主题配置复制为 JSON 对象或 TypeScript 预设，直接放入你的项目
- **可分享链接** — 主题状态编码在 URL 哈希中，方便与他人分享确切的配置
- **按基础库分别路由** — 为 [Takumi PDF](/theme-builder/takumi) 和 [Forme PDF](/theme-builder/forme) 提供独立的主题构建器
- **字体预览** — 在生成 PDF 之前，以实际大小查看所选正文和标题字体的效果
