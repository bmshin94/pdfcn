[MCP](https://modelcontextprotocol.io/) 是一个开放协议，标准化了应用程序向 LLM 提供上下文的方式。shadcn CLI 可以注册 MCP 服务器，以便您的编辑器可以发现注册表组件——包括您通过同一 CLI 从 **pdfcn** 安装的项目。

## 配置 MCP

运行：

```bash
npx shadcn@latest mcp init
```

在提示时选择您的 MCP 客户端，然后在该客户端中启用 MCP 服务器以完成设置。

## 使用方法

启用 MCP 后，您可以要求 IDE 使用 **Takumi** 和 **Forme** 模式以及 pdfcn 注册表组件。示例提示：

- 使用 **Table**、**Heading**、**Text** 和 **KeyValue** 构建发票布局。
- 向 PDF 文档添加 **QRCode** 和 **Signature**。
- 使用 **Graph**、**DataTable** 和 **PageHeader** 创建报告。
- 使用 **Section**、**Stack**、**Divider** 和 **KeepTogether** 布局 PDF。
- 使用 **PageBreak**、**PageNumber** 和 **PageFooter** 实现多页流程。

使用 `npx shadcn@latest add` 和每个文档页面中的 JSON URL 从该注册表安装组件。组件使用合理的默认值工作。
