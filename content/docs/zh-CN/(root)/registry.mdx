---
title: 注册表
description: 了解如何将 pdfcn 注册表与 shadcn CLI 一起使用。
---

**pdfcn** 注册表以 [shadcn 注册表格式](https://ui.shadcn.com/docs/registry) 提供 Takumi 和 Forme 组件、块和主题。在 `components.json` 中注册一次命名空间，然后使用 CLI 按名称拉取项目。

## 设置

为此站点添加 **registries** 条目。有关所有 `components.json` 字段和行为，请参阅 [shadcn 注册表文档](https://ui.shadcn.com/docs/registry)。

```json
{
  "registries": {
    "@pdfcn": "https://pdfcn.dev/r/{name}.json"
  }
}
```

您可以将 `@pdfcn` 替换为另一个命名空间；它只需要与您传递给 `shadcn add` 的内容匹配即可。

## 使用方法

项目按基础命名空间命名：`takumi/` 用于 Takumi，`forme/` 用于 Forme。

注册表文件遵循以下目标路径：

- 组件安装到 `components/ui/`。
- 块安装到已配置的块目录。

组件声明其依赖关系，因此安装组件不需要额外设置。

### Takumi

安装组件：

```bash
npx shadcn@latest add @pdfcn/takumi/text
```

安装块：

```bash
npx shadcn@latest add @pdfcn/takumi/invoice-minimal
```

不使用注册表别名时，使用完整 URL（如每个文档页面所示）：

```bash
npx shadcn@latest add https://pdfcn.dev/r/takumi/text.json
```

### Forme

安装组件：

```bash
npx shadcn@latest add @pdfcn/forme/text
```

安装块：

```bash
npx shadcn@latest add @pdfcn/forme/invoice-minimal
```

不使用注册表别名时，使用完整 URL（如每个文档页面所示）：

```bash
npx shadcn@latest add https://pdfcn.dev/r/forme/text.json
```
