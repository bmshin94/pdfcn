**pdfcn** 提供设计精美、无障碍且可自定义的 PDF 组件。基于 [Takumi](https://takumi.kane.tw/docs/pdf) 和 [Forme](https://docs.formepdf.com) 构建，并设计为可与 [shadcn CLI](https://ui.shadcn.com) 无缝协作。

## 设计理念

pdfcn 遵循 shadcn 的文档生成模型：可复制粘贴、可完全掌控的组件，零锁定，并提供开箱即用的合理默认值。

PDF 布局通常被当作一次性模板处理——使用渲染器特定的原语组装、重复的样式，以及脆弱的分页逻辑。pdfcn 采用了不同的方法。它贴近每个渲染器的原语，在 Takumi 和 Forme 之间保持统一的 API，并允许你在需要更多控制时随时深入底层渲染器。

目标很简单：让生成的 PDF 感觉像你技术栈的其他部分一样——可组合、可主题化、无障碍且易于自定义。

## 为什么选择 pdfcn？

大多数 PDF 组件方案要么过于死板，要么过于零散。pdfcn 专为希望快速交付又不放弃控制权的团队而设计：

- **拥有你的代码：** 将组件复制到你的项目中，自由定制一切。
- **快速上手：** 运行一条命令，即可使用生产级默认配置渲染你的第一份文档。
- **自由选择引擎：** 使用相同的组件 API 搭配 Takumi 或 Forme，需要时可随时降级到原始渲染器 API。
