## API 参考

### PdfPageNumber

| 属性       | 类型                            | 默认值                                       |
| ---------- | ------------------------------- | -------------------------------------------- |
| `format`   | `string`                        | 'Page &#123;page&#125; of &#123;total&#125;' |
| `align`    | `'left' \| 'center' \| 'right'` | 'center'                                     |
| `size`     | `'xs' \| 'sm' \| 'md'`          | 'sm'                                         |
| `fixed`    | `boolean`                       | false                                        |
| `muted`    | `boolean`                       | true                                         |
| `children` | `never`                         | -                                            |
