## 用法


## API 参考

### PdfWatermark

| 属性       | 类型                                                                       | 默认值 |
| ---------- | -------------------------------------------------------------------------- | ------ |
| `text`     | `string`                                                                   | -      |
| `opacity`  | `number`                                                                   | -      |
| `fontSize` | `number`                                                                   | -      |
| `color`    | `string`                                                                   | -      |
| `angle`    | `number`                                                                   | -      |
| `position` | `'center' \| 'top-left' \| 'top-right' \| 'bottom-left' \| 'bottom-right'` | -      |
| `fixed`    | `boolean`                                                                  | true   |
| `children` | `never`                                                                    | -      |
