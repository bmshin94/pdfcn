## 用法

```tsx

```

```tsx

```

## API 参考

### PdfQRCode

| 属性              | 类型                       | 默认值 |
| ----------------- | -------------------------- | ------ |
| `value`           | `string`                   | -      |
| `size`            | `number`                   | -      |
| `color`           | `string`                   | -      |
| `backgroundColor` | `string`                   | -      |
| `errorLevel`      | `'L' \| 'M' \| 'Q' \| 'H'` | -      |
| `margin`          | `number`                   | -      |
| `caption`         | `string`                   | -      |
| `children`        | `never`                    | -      |
