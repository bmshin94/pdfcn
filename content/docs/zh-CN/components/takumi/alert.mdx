## 用法

```tsx
import { PdfAlert } from "@/components/pdf/alert";
```

```tsx
<PdfAlert variant="info" title="Info">
  Alert body
</PdfAlert>
```

## API 参考

### PdfAlert

| 属性         | 类型                                          | 默认值   |
| ------------ | --------------------------------------------- | -------- |
| `variant`    | `'info' \| 'success' \| 'warning' \| 'error'` | `'info'` |
| `title`      | `string`                                      | -        |
| `children`   | `ReactNode`                                   | -        |
| `showIcon`   | `boolean`                                     | `true`   |
| `showBorder` | `boolean`                                     | `true`   |
