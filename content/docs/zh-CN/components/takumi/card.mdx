## 用法

```tsx

```

```tsx
<PdfCard title="Card">Card body</PdfCard>
```

## API 参考

### PdfCard

| 属性       | 类型                                 | 默认值      |
| ---------- | ------------------------------------ | ----------- |
| `title`    | `string`                             | -           |
| `children` | `ReactNode`                          | -           |
| `variant`  | `'default' \| 'bordered' \| 'muted'` | `'default'` |
| `padding`  | `'sm' \| 'md' \| 'lg'`               | `'md'`      |
| `wrap`     | `boolean`                            | `false`     |
