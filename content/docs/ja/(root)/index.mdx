**pdfcn** は、美しくデザインされ、アクセシブルでカスタマイズ可能な PDF コンポーネントを提供します。[Takumi](https://takumi.kane.tw/docs/pdf) と [Forme](https://docs.formepdf.com) 上に構築され、[shadcn CLI](https://ui.shadcn.com) とシームレスに連携するよう設計されています。

## 設計思想

pdfcn は、ドキュメント生成における shadcn のモデルに従います。所有できるコピー&ペーストのコンポーネントであり、ロックインはゼロで、すぐに使える適切なデフォルトを備えています。

PDF レイアウトは、レンダラー固有のプリミティブで組み立てられ、スタイルが重複し、ページ分割ロジックが脆弱な、使い捨てのテンプレートとして扱われることが多くあります。pdfcn は異なるアプローチを取ります。各レンダラーのプリミティブに寄り添いながら、Takumi と Forme の間で API を統一し、より細かい制御が必要な場合はいつでも基盤となるレンダラーに直接アクセスできます。

目標はシンプルです。生成される PDF を、あなたのスタックの他の部分と同じように感じられるものにすること——コンポーザブルで、テーマ対応で、アクセシブルで、カスタマイズしやすいものにすることです。

## なぜ pdfcn なのか？

ほとんどの PDF コンポーネントのセットアップは、独自の主張が強すぎるか、逆にまとまりがなさすぎます。pdfcn は、制御を犠牲にせずに素早くリリースしたいチームのために作られています。

- **コードを所有する：** コンポーネントをプロジェクトにコピーして、すべてをカスタマイズできます。
- **すぐに始められる：** 1 つのコマンドを実行するだけで、プロダクション対応のデフォルト設定で最初のドキュメントをレンダリングできます。
- **エンジンを選べる：** Takumi でも Forme でも同じコンポーネント API を使用し、必要に応じて生のレンダラー API に降りることができます。
