テーマビルダーをリリースしました。リアルタイムプレビュー、即時フィードバック、ワンクリックのコード出力を備えた、PDF テーマをカスタマイズするためのビジュアルエディタです。

### 新機能

- **リアルタイム PDF プレビュー** — 色、タイポグラフィ、余白、ページ設定を調整すると同時にテーマの適用結果をリアルタイムで確認
- **テーマピッカー** — 9 種類の組み込み[プリセット](/docs/themes)（Professional、Modern、Minimal、Executive、Corporate、Elegant、Vivid、Forest、Blueprint）を閲覧・切り替え
- **元に戻す / やり直し** — キーボードショートカット（⌘Z / ⌘⇧Z）に対応した完全な履歴管理
- **コード出力** — テーマ設定を JSON オブジェクトまたは TypeScript プリセットとしてコピーし、プロジェクトに組み込み可能
- **共有可能な URL** — テーマの状態が URL ハッシュにエンコードされるため、正確な設定を誰とでも共有できる
- **ベース別ルーティング** — [Takumi PDF](/theme-builder/takumi) と [Forme PDF](/theme-builder/forme) 用に個別のテーマビルダーを用意
- **フォントプレビュー** — PDF を生成する前に、選択した本文・見出しフォントを実際のサイズで確認
