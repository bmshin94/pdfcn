title: インストール
description: レジストリから PDF コンポーネント、ブロック、テーマをインストールします。
---

## 前提条件

[Takumi](https://takumi.kane.tw/docs/pdf) または [Forme](https://docs.formepdf.com) を実行できる React プロジェクト。

## インストール

以下のコマンドを実行して Takumi コンポーネントを追加します：

```bash
npx shadcn@latest add @pdfcn/takumi/text
```

Forme コンポーネントは `forme/` 名前空間を使用します：

```bash
npx shadcn@latest add @pdfcn/forme/text
```

レジストリはマッチするレンダラーの依存関係と、選択されたコンポーネントに必要な共有テーマユーティリティをインストールします。

## 使用方法

インストールされたコンポーネントをインポートし、レンダラーのドキュメントプリミティブ内で使用します：

```tsx
import { Document, Page } from "@/components/pdf/pdf-primitives";
import { PdfcnThemeProvider } from "@/components/pdf/theme-provider";
import { Text } from "@/components/pdf/text";

export function Invoice() {
  return (
    <Document>
      <Page size="A4">
        <PdfcnThemeProvider>
          <Text variant="xl">Invoice</Text>
        </PdfcnThemeProvider>
      </Page>
    </Document>
  );
}
```

Forme の場合、`@formepdf/react` から `Document` と `Page` を使用します。インストールされた pdfcn コンポーネント API は同じです。

## ブロックのインストール

ブロックはレジストリコンポーネントで構成された完全なドキュメントテンプレートです：

```bash
npx shadcn@latest add @pdfcn/takumi/invoice-minimal
```

`forme/` 名前空間を使用して同等の Forme ドキュメントを取得します：

```bash
npx shadcn@latest add @pdfcn/forme/invoice-minimal
```

## テーマのインストール

pdfcn は `PdfcnThemeProvider` と統合するテーマプリセットを提供します：

```bash
npx shadcn@latest add @pdfcn/takumi/theme-minimal
```

Forme の場合：

```bash
npx shadcn@latest add @pdfcn/theme-minimal
```
