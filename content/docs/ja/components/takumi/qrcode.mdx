## 使用方法

```tsx
import { PdfQRCode } from "@/components/pdf/qrcode";
```

```tsx
<PdfQRCode value="https://pdfcn.dev" />
```

## API リファレンス

### PdfQRCode

| プロパティ        | 型                         | デフォルト |
| ----------------- | -------------------------- | ---------- |
| `value`           | `string`                   | -          |
| `size`            | `number`                   | -          |
| `color`           | `string`                   | -          |
| `backgroundColor` | `string`                   | -          |
| `errorLevel`      | `'L' \| 'M' \| 'Q' \| 'H'` | -          |
| `margin`          | `number`                   | -          |
| `caption`         | `string`                   | -          |
| `children`        | `never`                    | -          |
