
## API リファレンス

### Link

| プロパティ  | 型                                  | デフォルト  |
| ----------- | ----------------------------------- | ----------- |
| `href`      | `string`                            | -           |
| `align`     | `'left' \| 'center' \| 'right'`     | `'left'`    |
| `color`     | `string`                            | -           |
| `variant`   | `'default' \| 'muted' \| 'primary'` | `'default'` |
| `underline` | `'always' \| 'none'`                | `'always'`  |
