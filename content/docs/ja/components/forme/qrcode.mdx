## 使い方

```tsx

```

```tsx

```

## APIリファレンス

### PdfQRCode

| プロパティ        | 型                         | デフォルト |
| ----------------- | -------------------------- | ---------- |
| `value`           | `string`                   | -          |
| `size`            | `number`                   | -          |
| `color`           | `string`                   | -          |
| `backgroundColor` | `string`                   | -          |
| `errorLevel`      | `'L' \| 'M' \| 'Q' \| 'H'` | -          |
| `margin`          | `number`                   | -          |
| `caption`         | `string`                   | -          |
| `children`        | `never`                    | -          |
