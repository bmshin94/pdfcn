## 使用方法

```tsx
import { PdfCard } from "@/components/pdf/card";
```

```tsx
<PdfCard title="Card">Card body</PdfCard>
```

## API リファレンス

### PdfCard

| プロパティ | タイプ                               | デフォルト  |
| ---------- | ------------------------------------ | ----------- |
| `title`    | `string`                             | -           |
| `children` | `ReactNode`                          | -           |
| `variant`  | `'default' \| 'bordered' \| 'muted'` | `'default'` |
| `padding`  | `'sm' \| 'md' \| 'lg'`               | `'md'`      |
| `wrap`     | `boolean`                            | `false`     |
