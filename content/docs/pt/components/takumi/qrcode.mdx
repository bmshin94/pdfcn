## Uso

```tsx
import { PdfQRCode } from "@/components/pdf/qrcode";
```

```tsx
<PdfQRCode value="https://pdfcn.dev" />
```

## Referência da API

### PdfQRCode

| Propriedade       | Tipo                       | Padrão |
| ----------------- | -------------------------- | ------ |
| `value`           | `string`                   | -      |
| `size`            | `number`                   | -      |
| `color`           | `string`                   | -      |
| `backgroundColor` | `string`                   | -      |
| `errorLevel`      | `'L' \| 'M' \| 'Q' \| 'H'` | -      |
| `margin`          | `number`                   | -      |
| `caption`         | `string`                   | -      |
| `children`        | `never`                    | -      |
