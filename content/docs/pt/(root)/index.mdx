**pdfcn** oferece componentes PDF lindamente projetados, acessíveis e personalizáveis. Construído sobre [Takumi](https://takumi.kane.tw/docs/pdf) e [Forme](https://docs.formepdf.com), e projetado para funcionar perfeitamente com a [CLI do shadcn](https://ui.shadcn.com).

## Filosofia

pdfcn segue o modelo shadcn para geração de documentos: componentes de copiar e colar que você pode possuir totalmente, sem nenhum tipo de dependência forçada (lock-in) e com padrões sensatos que funcionam imediatamente.

Layouts de PDF costumam ser tratados como modelos avulsos — montados com primitivas específicas do renderizador, estilos duplicados e lógica de quebra de página frágil. O pdfcn adota uma abordagem diferente. Ele permanece próximo das primitivas de cada renderizador, mantém uma API familiar entre Takumi e Forme, e permite que você acesse o renderizador subjacente sempre que precisar de mais controle.

O objetivo é simples: fazer com que os PDFs gerados pareçam parte do restante do seu stack — combináveis, com suporte a temas, acessíveis e fáceis de personalizar.

## Por que pdfcn?

A maioria das configurações de componentes PDF é excessivamente opinativa ou excessivamente dispersa. O pdfcn foi criado para equipes que querem lançar rapidamente sem abrir mão do controle:

- **Seja dono do seu código:** Copie os componentes para o seu projeto e personalize tudo.
- **Comece rápido:** Execute um único comando e renderize seu primeiro documento com padrões prontos para produção.
- **Escolha seu mecanismo:** Use a mesma API de componentes com Takumi ou Forme, e acesse as APIs nativas do renderizador quando precisar.
