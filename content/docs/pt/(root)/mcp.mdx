[MCP](https://modelcontextprotocol.io/) é um protocolo aberto que padroniza como as aplicações fornecem contexto para LLMs. O CLI do shadcn pode registrar um servidor MCP para que seu editor possa descobrir componentes do registro—incluindo os itens que você instala do **pdfcn** através do mesmo CLI.

## Configurar MCP

Execute:

```bash
npx shadcn@latest mcp init
```

Escolha seu cliente MCP quando solicitado, depois habilite o servidor MCP nesse cliente para concluir a configuração.

## Uso

Com o MCP habilitado, você pode pedir ao seu IDE para trabalhar com padrões **Takumi** e **Forme** e componentes do registro pdfcn. Exemplos de prompts:

- Construir um layout de fatura com **Table**, **Heading**, **Text** e **KeyValue**.
- Adicionar um **QRCode** e uma **Signature** a um documento PDF.
- Criar um relatório com **Graph**, **DataTable** e **PageHeader**.
- Dispor um PDF usando **Section**, **Stack**, **Divider** e **KeepTogether**.
- Implementar um fluxo de múltiplas páginas com **PageBreak**, **PageNumber** e **PageFooter**.

Instale componentes deste registro com `npx shadcn@latest add` e a URL JSON de cada página de documentação. Os componentes funcionam com valores padrão adequados.
