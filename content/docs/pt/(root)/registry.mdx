title: Registro

O registro **pdfcn** fornece componentes, blocos e temas de Takumi e Forme no [formato de registro do shadcn](https://ui.shadcn.com/docs/registry). Registre o namespace uma vez em `components.json`, depois obtenha itens por nome com o CLI.

## Configuração

Adicione uma entrada **registries** para este site. Consulte a [documentação do registro do shadcn](https://ui.shadcn.com/docs/registry) para todos os campos e comportamentos do `components.json`.

```json
{
  "registries": {
    "@pdfcn": "https://pdfcn.dev/r/{name}.json"
  }
}
```

Você pode substituir `@pdfcn` por outro namespace; ele precisa corresponder ao que você passa para `shadcn add`.

## Uso

Os itens são nomeados por base: `takumi/` para Takumi e `forme/` para Forme.

Os arquivos de registro seguem estes destinos:

- Os componentes são instalados em `components/ui/`.
- Os blocos são instalados no diretório de blocos configurado.

Os componentes declaram suas dependências, portanto instalar um componente não requer configuração adicional.

### Takumi

Instalar um componente:

```bash
npx shadcn@latest add @pdfcn/takumi/text
```

Instalar um bloco:

```bash
npx shadcn@latest add @pdfcn/takumi/invoice-minimal
```

Sem um alias de registro, use a URL completa (como em cada página de documentação):

```bash
npx shadcn@latest add https://pdfcn.dev/r/takumi/text.json
```

### Forme

Instalar um componente:

```bash
npx shadcn@latest add @pdfcn/forme/text
```

Instalar um bloco:

```bash
npx shadcn@latest add @pdfcn/forme/invoice-minimal
```

Sem um alias de registro, use a URL completa (como em cada página de documentação):

```bash
npx shadcn@latest add https://pdfcn.dev/r/forme/text.json
```
